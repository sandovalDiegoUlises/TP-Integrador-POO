## 📌 PROPÓSITO DEL PROYECTO: 
Administrar el inventario de libros y gestionar los préstamos a socios (Estudiantes y Docentes) de una biblioteca. El sistema aplica diferentes reglas de negocio y límites según el tipo de socio, realiza control de vencimientos de manera dinámica y genera reportes de estado y listados.

## 🗓️ VERSIÓN o FECHA: 
Versión 1.0 (Noviembre 2026)

## 🏁 CÓMO INICIAR ESTE PROYECTO: 
Compilar todos los archivos `.java` asegurando que se encuentren organizados dentro del paquete `biblioteca`. Luego, ejecutar el método `main` de la clase principal `GestionBiblioteca`.

## 📋INSTRUCCIONES PARA EL USUARIO:
1. Al ejecutar el programa, la consola le solicitará ingresar el nombre de la biblioteca.
2. El sistema inicializará automáticamente un set de datos de prueba (libros y socios base) para que pueda probar las funciones inmediatamente.
3. Interactúe con el sistema ingresando el número de la opción deseada en el menú principal (del 1 al 11) y presionando Enter.
4. Siga las instrucciones en pantalla para introducir datos requeridos, como el DNI numérico del socio o el título exacto de los libros.
5. Para salir del sistema y finalizar la ejecución de manera segura, ingrese la opción 0.
